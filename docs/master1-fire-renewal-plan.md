## 2. 핵심 문제점

### 2-1. 포지셔닝·구조
1. **브랜드 혼재**: 달인명인 / 달인명장 / 명장 에이전트 / Master Agent / 점검24 / 소방점검24 가 한 사이트에 섞여 있음
2. **소방 메뉴가 4곳에 흩어짐**: 점검·관리 > 소방점검, 달인명인 > 소방점검·소방공사·방화셔터·비상방송, 소방자체점검 메뉴, 공공·관리팀. 소방점검·소방공사·소독방역은 메뉴가 중복됨
3. **비핵심 카테고리가 신뢰도를 깎음**: 노트북, 심리상담, 운동코칭, 안경, 가방지갑 등. B2B 소방 고객(관리소장, 건물주, 시설팀)에게는 "잡화점"처럼 보임
4. 홈 메인 메시지("시설물 수리/법정점검/생활서비스")가 고객이 실제로 겪는 문제(점검 기한, 과태료, 지적사항)를 말하지 않음

### 2-3. 콘텐츠·법령 표현
- 2022.12.1 시행 「소방시설 설치 및 관리에 관한 법률」 이후 공식 용어는 **작동점검 / 종합점검**인데, 사이트에서 "작동기능점검 / 종합정밀점검"(구 용어)과 신 용어가 섞여 있음
- FAQ 과태료 안내가 "최대 수백만 원"처럼 모호함 → 근거 조문을 달아 구체적으로 표기
- "과태료 리스크 제로(Zero) 보장" 같은 단정 표현은 표시·광고 분쟁 소지가 있음 → "과태료 예방 관리"로 순화 권장
- 셀프점검(10만원)은 **누가, 어떤 건물에서 직접 점검할 수 있는지** 대상 범위를 명확히 써야 함. 종합점검 대상은 관리업자 등이 점검해야 하므로 오인되지 않게 표시
- 회사소개에 "흑백요리사" 인용 → 타 방송 IP 인용이라 삭제 권장
- 소방시설관리업 등록번호, 보유 소방시설관리사 수, 점검 실적, 영업배상보험 등 **B2B 신뢰 정보가 없음**

> ⚠️ 법령 수치(점검 시기, 제출 기한, 벌칙·과태료)는 게시 전에 국가법령정보센터 원문과 소방시설관리사의 검수를 받을 것.

## 3. 개편 방향 (포지셔닝)

**"소방 법정의무, 점검부터 지적사항 보수·월 관리까지 한 번에"**

- 타깃: ① 관리소장·시설팀(공동주택, 빌딩·상가) ② 건물주·소상공인(고시원, 숙박, 학원, 상가) ③ 학교·공공기관
- 차별점: 점검만 하고 떠나는 업체가 아니라, **지적사항을 달인 네트워크가 바로 보수**하고 월 관리로 이어지는 구조
- 브랜드 구조(권장): 사이트 대표 브랜드는 **점검24(소방)** 로 통일하고, **달인명인**은 "보수 전문가 네트워크" 이름으로 하위에 둠. Master Agent, 명장 에이전트 표기는 정리

## 6. 홈 화면 구성안

1. **히어로**: "소방점검 기한, 놓치면 과태료입니다" + [우리 건물 점검 대상 확인] [무료 견적] + 대표번호
2. **문제 선택 카드** (고객 상황별 진입): 점검 시기가 됐어요 / 소방서 지적을 받았어요 / 화재안전조사가 예정돼 있어요 / 안전관리자를 대신해 줄 사람이 필요해요 / 오작동·경보가 울려요(긴급)
3. **원스톱 프로세스**: 점검 → 보고서 제출 → 지적사항 보수 → 월 관리 (현 5단계 Flow 재활용)
4. **신뢰 숫자**: 누적 점검 건수, 보수 완료율, 관리 중인 건물 수, 소방시설관리사 수
5. **건물 유형별 바로가기**
6. **해결사례 Before/After** (사진 필수)
7. **소방 전문가 (달인) 소개**: 소방 분야만 노출
8. **FAQ 5개 + 법령 자료실**
9. **하단 고정 CTA** (모바일): 전화 / 카톡 / 견적
