기능 3 · AI 자랑 에이전트

"오늘 한 작업, 자랑해 보세요!"는 안에서 먼저, 밖으로 나중에

자랑 에이전트를 두 단계로 나눕니다. 3-A는 카톡 보고를 끝낸 작업을 사진통 자랑터에 올립니다. 3-B는 자랑터에서 반응이 확인된 작업을 인스타·블로그로 내보냅니다. 처음부터 외부 SNS를 권하면 부담스럽지만, 사진통 안에서 먼저 칭찬을 받으면 밖으로 올릴 자신감이 생깁니다.

3-A 카톡 보고→고객 동의→사진통 자랑터 게시→좋아요·스크랩→3-B 인스타·블로그 확산

반응이 확인된 자랑을 SNS 글로

자랑터에서 반응이 좋았던 작업을 골라 외부 SNS용 글로 바꿔 줍니다. 라벨과 음성 메모를 근거로 채널에 맞는 형식의 글을 쓰고, 사용자는 확인하고 올리기만 합니다.

외부 포스팅을 제안하는 순간
  • 반응자랑터 게시물이 좋아요 30개 또는 스크랩 10개를 넘었을 때"이 작업, 인스타에도 올려볼까요?"

블로그·인스타에 올리는 방법
방법 1 · 누구나

원탭 공유

사진통이 사진 순서와 글을 준비해 두고, 사용자는 앱을 골라 붙여넣기만 합니다. 계정 연동이 필요 없어 첫 사용자도 바로 씁니다.

  • 인스타그램 비포·애프터 카드와 캐러셀 이미지를 저장하고, 캡션·해시태그를 복사한 채 인스타 앱 열기
  • 네이버 블로그 본문을 문단별로 복사하고, 사진을 본문 순서대로 저장한 뒤 블로그 앱 열기
사용자 할 일 · 붙여넣기 1번 + 올리기
방법 2 · 계정 연동 (프로 플랜)

선택하면 자동 게시

인스타그램 비즈니스 계정을 한 번 연동해 두면, 사용자가 제안 카드에서 "올리기"만 눌러도 사진통이 대신 게시하거나 원하는 시간에 예약합니다.

  • 인스타그램 비즈니스·크리에이터 계정 연동 후 즉시 게시 또는 예약 게시 (반응 좋은 저녁 8~9시 추천)
  • 네이버 블로그 외부 자동 게시가 제한적이라 "임시저장용 글 + 사진 묶음"을 만들어 두고, 앱에서 확인 후 발행
사용자 할 일 · 버튼 1번
채널별 자동 편집

인스타는 1:1·4:5 비율 카드와 짧은 캡션, 블로그는 문제→원인→작업→결과→관리 팁 순서의 긴 후기와 지역 키워드 제목.
