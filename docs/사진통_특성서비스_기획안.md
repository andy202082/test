# 사진통 특성 서비스 기획안
### "현장 사진 한 장, 보고부터 SNS 홍보까지"

> 작업사진 한 장에서 출발해 고객의 성공을 돕는 회사
> **작업의 기록을 사업의 자산으로 쌓으세요.**

---

## 0. 한 장 요약

| 구분 | 내용 |
|---|---|
| 정체성 | 현장 작업자를 위한 **"찍기 → 정리 → 보고 → 홍보 → 일감"** 올인원 앱 |
| 핵심 차별점 | 보고용으로 찍은 사진이 **자동으로 홍보 자산**이 되고, 사진통 안에서 **노출·시상**까지 이어짐 |
| 타깃 | 숨고·당근·지역 카페에서 일감을 구하는 모든 현장 업종 (집수리, 인테리어, 설비, 청소, 홈케어, 방역, 점검, 소규모 공사 등) |
| 사용자 가치 | 반복 작업(사진 정리·보고서)은 줄고, 홍보 자료와 고객 신뢰는 쌓인다 |
| 성장 엔진 | ① 습관(매일 촬영) ② SNS 포스팅 제안(외부 확산) ③ 사진통 쇼케이스·시상(내부 자랑터) |

## 1. 왜 이 서비스인가 (문제 정의)

현장 자영업자·작업팀의 현실:

1. **사진은 매일 수십 장 찍는다** → 갤러리에 섞여서 다시 못 찾는다.
2. **보고서/사진대지 만들기가 귀찮다** → 퇴근 후 PC에서 한글/엑셀로 붙여넣기.
3. **홍보가 중요하단 건 안다** → 그런데 "뭘 올리지, 글은 뭐라 쓰지"에서 멈춘다.
4. **숨고·당근에서 선택받으려면 포트폴리오가 필요** → 정리된 사례가 없다.

> 💡 인사이트: 사용자는 이미 **홍보에 필요한 원재료(작업사진)를 매일 만들고 있다.**
> 사진통은 이 원재료를 "버려지는 사진"에서 "일감을 부르는 자산"으로 바꿔준다.

## 2. 핵심 사용자 (페르소나)

| 페르소나 | 상황 | 사진통에서 원하는 것 |
|---|---|---|
| **1인 집수리 사장님 (40~50대)** | 하루 2~3건, 폰으로만 일함, SNS 서툼 | 버튼 몇 번에 보고서 + 글까지 써주는 것 |
| **청소·홈케어 업체 (2~5인 팀)** | 직원이 찍고 사장이 확인 | 팀원 사진 한곳 모으기, 비포·애프터 홍보 |
| **점검·설비 업체** | 점검 보고서 의무, 사진 대지 필수 | 양식 맞춘 사진대지 자동 생성, 이력 관리 |
| **인테리어·공사 소규모 회사** | 공정별 기록, 고객 소통 중요 | 공정 타임라인 공유, 시공사례 포트폴리오 |

**설계 원칙:** "50대 사장님이 장갑 낀 손으로, 현장에서, 30초 안에" 쓸 수 있어야 한다.

## 3. 핵심 루프 (서비스의 심장)

```
   ┌──────────────────────────────────────────────────────────┐
   │                                                          │
   ▼                                                          │
① 찍는다 ──▶ ② 자동 라벨 ──▶ ③ 사진대지 ──▶ ④ 자산함에 쌓임   │
 (원탭)        (AI 추천)       (1탭 PDF/링크)   (일자·현장별)   │
                                                 │             │
                                                 ▼             │
             ⑦ 문의·일감 ◀── ⑥ 사진통 쇼케이스 ◀── ⑤ "오늘 작업으로│
               증가            노출·시상            SNS 포스팅    │
                │                                   해보세요"    │
```

- **①~④ = 업무 도구 (매일 쓰는 이유)**
- **⑤~⑦ = 성장 도구 (계속 쓰는 이유, 사진통만의 특장점)**

## 4. 기능 기획

### 4-1. 촬영 — "많이 찍게"

| 기능 | 설명 | 사용률 포인트 |
|---|---|---|
| **현장(작업) 단위 촬영** | 앱 열면 바로 카메라. "새 현장" 1탭 → 이후 사진은 자동으로 해당 현장에 묶임 | 갤러리 뒤죽박죽 문제 해결 |
| **전·중·후 단계 버튼** | 촬영 화면 하단에 `작업 전 / 작업 중 / 작업 후` 토글 | 비포·애프터 콘텐츠 자동 확보 |
| **비포 고스트 가이드** | '작업 후' 촬영 시 '작업 전' 사진을 반투명으로 겹쳐 같은 구도로 찍게 유도 | 홍보용 비포애프터 품질 ↑ |
| **촬영 체크리스트** | 업종별 "꼭 찍을 컷" 안내 (예: 누수 → 원인부/배관/마감) | 빠진 컷 없이 보고 가능 |
| **자동 메타정보** | 날짜·시간·위치(주소 자동) 기록, 사진에 워터마크(선택) | 증빙 신뢰도 |
| **오프라인 촬영** | 지하·현장에서 저장 후 자동 업로드 | 현장 실사용성 |

### 4-2. 간편 라벨링 — "손 안 대고 정리"

| 기능 | 설명 |
|---|---|
| **AI 자동 라벨 추천** | 사진 인식 → "욕실 / 실리콘 재시공 / 작업 후" 같이 칩으로 추천, 탭 한 번에 확정 |
| **업종별 라벨 템플릿** | 가입 시 업종 선택 → 자주 쓰는 공정·부위 라벨이 기본 세팅 |
| **음성 라벨** | 🎤 길게 눌러 "안방 창틀 곰팡이 제거" 말하면 라벨 + 메모 자동 입력 |
| **일괄 라벨** | 여러 장 선택 → 한 번에 적용 |
| **최근 라벨 기억** | 같은 현장/같은 고객에서 쓰던 라벨 우선 노출 |

> 목표: **사진 1장당 라벨 작업 3초 이내**, 라벨 완료율 80% 이상.

### 4-3. 사진대지 — "1탭 보고서"

| 기능 | 설명 |
|---|---|
| **용도별 템플릿** | 보고용(관공서/원청), 점검용(점검표 양식), 고객용(깔끔한 카드형), 견적용 |
| **자동 배치** | 라벨 순서·전중후 단계대로 자동 정렬, 2/4/6컷 레이아웃 선택 |
| **회사 브랜딩** | 로고·상호·연락처·담당자 서명 자동 삽입 |
| **출력·공유** | PDF / 이미지 / **카카오톡 링크 공유** (고객이 웹에서 바로 열람) |
| **고객 홍보 동의 받기** | 고객용 링크 하단 "시공 사례로 소개해도 될까요? ✅" → 동의 시 홍보 사용 가능 표시 |

> ⭐ **고객 동의 버튼**이 이후 SNS·쇼케이스 노출의 법적·심리적 안전장치이자,
> 고객이 "인정받는 느낌"을 주는 신뢰 장치가 된다.

### 4-4. 자산함 — "일자별로 쌓이는 내 사업 기록"

- **캘린더/타임라인 뷰**: 날짜별로 어떤 현장을 했는지 한눈에
- **현장·고객·분야별 필터**: "작년 ○○아파트 욕실" 3초 검색
- **나의 실적 카드**: "이번 달 작업 32건 · 사진 418장 · 사진대지 27건 · 포스팅 9건"
- **재방문 고객 이력**: 같은 주소 재작업 시 이전 기록 자동 표시 (AS·재계약 영업에 활용)

> 메시지: **"사진이 쌓일수록 반복 작업은 줄고, 홍보 자료와 고객 신뢰는 쌓입니다."**

### 4-5. ⭐ SNS 포스팅 제안 — "오늘 하신 작업으로 SNS 포스팅 해보세요"

인스타그램이 "추억 만들기"를 제안하듯, 사진통은 **"오늘의 작업 포스팅"을 먼저 만들어서 제안**한다.
사용자는 만들 필요 없이 **고르고 → 확인하고 → 올리기**만 한다.

#### (1) 제안 타이밍 (트리거)

| 트리거 | 메시지 예시 |
|---|---|
| 사진대지 생성 직후 | "깔끔하게 끝났네요! 이 작업, 비포·애프터로 올려볼까요? ✨" |
| 퇴근 시간 (18~20시) 푸시 | "오늘 3곳 작업하셨어요. 포스팅 초안 만들어 뒀어요 📸" |
| 고객 홍보 동의 도착 시 | "고객님이 사례 소개에 동의했어요! 지금 올리기 딱 좋아요" |
| 주간 리포트 (일요일 저녁) | "이번 주 베스트 작업 TOP3로 카드뉴스 만들었어요" |
| 3일 이상 미포스팅 | "꾸준한 포스팅이 문의를 늘려요. 지난 작업 중 하나 올려볼까요?" |

> 피로도 관리: 하루 최대 1회 푸시, 사용자가 '제안 빈도' 직접 조절.

#### (2) 자동 생성되는 콘텐츠

| 형태 | 내용 | 채널 |
|---|---|---|
| **비포·애프터 카드** | 좌우/상하 비교, 슬라이드 비교 이미지 | 인스타 피드, 당근 |
| **캐러셀(여러 장)** | 표지 → 문제 → 과정 → 결과 → 연락처 | 인스타 |
| **숏폼 영상** | 사진 자동 슬라이드쇼 + 음악 + 자막 (15초) | 릴스, 쇼츠, 틱톡 |
| **블로그 글 초안** | 제목·본문(문제→원인→작업→결과→팁)·지역 키워드·사진 배치 | 네이버 블로그 |
| **짧은 홍보글** | 3줄 요약 + 해시태그 | 인스타, 당근 비즈프로필, 숨고 포트폴리오 |

**AI 글쓰기 옵션**
- 톤 선택: `전문가형` / `친근한 사장님형` / `꼼꼼 설명형`
- **지역 + 업종 해시태그 자동**: `#수원욕실리폼 #영통동실리콘 #수원집수리`
- 라벨·메모·음성을 근거로 작성 → "내가 한 일"이 정확히 들어감

#### (3) 안전장치 (자동 개인정보 가리기)

- 얼굴, 차량 번호판, 동·호수, 문패, 택배 송장, 서류 자동 감지 → **블러 처리**
- 고객 홍보 미동의 현장은 "공개 전 확인" 경고

#### (4) 원클릭 업로드

- 인스타/페이스북: 공유 시트로 이미지 + 캡션 자동 복사 상태로 전달
- 네이버 블로그: 글 + 사진 순서대로 복사, 블로그 앱 바로 열기
- 당근 비즈프로필·숨고: 이미지 저장 + 문구 복사
- 공유물 하단에 작은 표시: **"📸 사진통으로 기록했어요"** (선택 해제 가능) → 자연스러운 바이럴

### 4-6. ⭐ 사진통 쇼케이스 — "각 회사의 자랑터"

#### (1) 업체 미니홈 (포트폴리오 페이지)
- 자동 생성 URL: `sajintong.com/@업체명`
- 구성: 대표 사례, 분야별 시공사례, 작업 건수·연차, 고객 동의 후기, **[문의하기] 버튼**
- 명함·현수막·차량용 **QR코드** 자동 생성 → 오프라인 → 온라인 연결
- 숨고·당근 프로필에 링크 걸어 **포트폴리오로 활용**

#### (2) 분야별 쇼케이스 피드
- 사진통 앱/웹에 `욕실 · 주방 · 도배 · 청소 · 방역 · 설비 · 점검 · 인테리어` 분야 탭
- 지역 필터 (시·구 단위) → **동네 고객이 업체를 찾는 창구**로 발전
- 노출 기준: 품질(사진·라벨 완성도) + 최신성 + 고객 동의 여부

#### (3) 이달의 우수 업체 · 사용자 시상

| 시상 | 기준 | 혜택 |
|---|---|---|
| 🏆 **이달의 우수 업체** (분야별) | 작업 기록 꾸준함 + 포스팅 수 + 고객 반응 | 쇼케이스 메인 노출, 인증 배지, 프리미엄 3개월 |
| 📸 **이달의 베스트 비포·애프터** | 사용자 투표 + 운영진 선정 | 사진통 공식 SNS 소개, 상품 |
| 🔥 **꾸준왕** | 연속 기록 일수 | 배지, 리포트 공유 카드 |
| 🌱 **신인상** | 가입 3개월 내 성장 | 노출 부스트 |

- 수상 결과를 **"수상 인증 카드"**로 만들어 사용자가 자기 SNS에 자랑 → 또 바이럴
- 배지는 미니홈·사진대지·공유물에 표시 → 고객 신뢰 ↑

> 결과: 개인 자영업자든 회사·팀이든 **사진통이 자연스럽게 "우리 회사 자랑터"**가 된다.

### 4-7. 팀 기능 (회사·팀 플랜)

> 원칙: **기록·보고는 무료로 넓게** 깔고, **홍보·성장 기능에서 유료 전환**.

### 7-2. 타깃 채널

1. **숨고·당근 고수 커뮤니티** — "숨고 포트폴리오 5분 만에 채우기" 콘텐츠
2. **업종 네이버 카페/밴드** (집수리, 청소창업, 설비, 인테리어 협회)
3. **유튜브·쇼츠** — 현장 사장님 비포·애프터 숏폼 (사진통으로 만든 영상 자체가 광고)
4. **자재상·철물점·교육기관 제휴** — 계산대 QR, 창업교육 수강생 무료 프로
5. **점검 분야 B2B** — 점검 보고서 양식 제공으로 업체 단위 도입

### 7-3. 런칭 캠페인 아이디어

- **"내 인생 비포·애프터 챌린지"**: 사진통으로 만든 비포·애프터 올리고 `#사진통챌린지` → 매주 시상
- **"숨고 포트폴리오 무료 정리해드립니다"**: 기존 사진 업로드 → 자동 분류·미니홈 생성 (초기 자산 확보 + 즉시 가치 체험)
- **추천 프로그램**: 동료 업체 초대 시 양쪽 프로 1개월 (같은 업종끼리 잘 퍼짐)

### 7-4. 그로스 루프 (자연 확산 구조)

```
사장님이 포스팅 ──▶ "사진통으로 기록했어요" 노출 ──▶ 동종 업체가 봄 ──▶ 가입
```

## 12. 결론 — 사진통의 최대 특장점

> 다른 앱은 **사진을 정리**해 줍니다.
> 사진통은 **사진으로 일감을 만들어** 드립니다.

1. **찍기만 하면** 라벨·사진대지가 끝나고 (업무 시간 절약)
2. **"오늘 작업으로 포스팅 해보세요"** 제안으로 홍보가 습관이 되고 (외부 확산)
3. **사진통 쇼케이스·시상**으로 각 회사의 자랑터가 되며 (내부 노출)
4. 결국 **문의와 일감이 늘어나는 것**을 숫자로 체감합니다. (고객의 성공)

**현장 사진 한 장, 보고부터 SNS 홍보까지. — 사진통**
