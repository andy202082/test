# 건물관리 달인명인 웹사이트

소방점검 + 소방공사 + 화재·누수보험을 **한번에** 해결하는 "건물관리 달인명인" 웹사이트 프로젝트입니다.
(기존 master1.kr 사이트를 소방 중심으로 개편)

## 폴더 구조

```
.
├─ src/                     ← 내용 수정은 여기서
│  ├─ content.py            모든 문구·메뉴·연락처·지사·달인·FAQ·연혁 (이 파일만 고치면 됨)
│  └─ build.py              content.py 를 읽어 site/ 의 HTML 페이지를 만드는 생성기
├─ site/                    ← 실제 배포되는 웹사이트 (이 폴더만 호스팅에 올리면 됨)
│  ├─ index.html            메인 (방화문 인트로 → 5개의 문 → 견적 …)     ┐
│  ├─ fire-safety.html      01 소방안전                                  │
│  ├─ fire-construction.html 02 소방공사                                 │ build.py 가
│  ├─ building.html         03 건물관리                                  │ 자동 생성
│  ├─ inspection.html       04 법정점검                                  │ (직접 수정 X)
│  ├─ story.html            05 STORY (스토리 · 걸어온 길 · 지사)          │
│  ├─ experts.html          검증된 달인 12인 프로필                       │
│  ├─ sitemap.xml, robots.txt                                           ┘
│  ├─ 404.html, manifest.webmanifest
│  └─ assets/  css/style.css · js/main.js · img/ (직접 편집)
└─ docs/                    기획서, 배포·도메인 가이드, 작업 기록, 화면 캡처
```

## 수정 → 확인 순서

1. `src/content.py` 에서 문구 수정 (디자인은 `site/assets/css/style.css`)
2. 페이지 다시 만들기

```bash
python3 src/build.py
```

3. 미리보기 (저장하면 자동 새로고침)

```bash
npx live-server@1.2.2 site --port=8080
```

## 작업·배포 방식 (이진숙 홈페이지 profiling.kr 과 동일)

| 구분 | 주소 | 내용 |
|---|---|---|
| 운영 버전 | `도메인/` | `main` 브랜치의 `site/` 가 GitHub Pages 로 자동 배포 |
| 미리보기 버전 | `도메인/v1/`, `도메인/v2/` … | 디자인을 바꿀 때마다 사이트 전체를 버전 폴더로 복사해 검토 |

**새 디자인 미리보기 만들기**

```bash
python3 src/build.py --snapshot v2
```

→ `site/v2/` 에 현재 사이트가 통째로 복사되고, 배포 후 `도메인/v2/` 에서 볼 수 있습니다.
(미리보기 페이지는 검색엔진에 노출되지 않도록 `noindex` 가 자동으로 붙습니다.)

**흐름**: 수정 → `python3 src/build.py` → (필요하면 `--snapshot vN`) → 커밋 → main 에 합치기 → 1~2분 뒤 자동 반영

## "문 여는" 디자인 3곳

- **메인 인트로**: 빨간 방화문이 화면을 막고 있다가, 스크롤하면 양쪽으로 열리며 "한번에 달인명인"이 나타남
- **5개의 문**: 메뉴 큰 항목 5개가 방화문으로 표시되고, 화면에 들어오면 차례로 열리며 하위 메뉴가 보임
- **상단 메뉴 / 하위 페이지**: 메뉴에 마우스를 올리면 문 두 짝이 좌우로 밀려나며 하위 메뉴가 열리고, 하위 페이지는 들어갈 때 문이 열림

## 로고 (4가지 방향 중 C형 채택)

| 형 | 모양 | 쓰이는 곳 |
|---|---|---|
| **C · 배지형 (대표 로고)** | 어두운 둥근 사각형 + 빨간 지붕 + **소방** (아래 "건물관리 / 달인명인") | 헤더·푸터 아이콘, 메인 방화문 인트로, 파비콘·앱 아이콘(`assets/img/icon-*.png`), 공유 이미지(`og.png`) |
| A · 엠블럼형 | 지붕 + 건물 + 점검 완료 체크 | 견적 섹션, STORY 페이지 |
| B · 낙관(도장)형 | 빨간 도장 2×2 "달인/명인" | 하단 빨간 CTA 띠(모든 페이지), STORY 페이지 |
| D · 헤더 가로형 | [소방 배지] + 두 줄 "건물관리 / 달인명인" | 상단 헤더(흰 배경), 푸터(어두운 배경) |

로고는 이미지 파일이 아니라 SVG/CSS 로 그려져 있어 어떤 크기에서도 선명합니다 (`src/build.py` 의 `BADGE`, `EMBLEM_A`, `SEAL_B`).
