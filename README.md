## 📷 사진통 (Photo Box)

브라우저에서 동작하는 간단한 사진 보관 앱입니다. 설치할 것이 없어요.

### 기능
- 사진 추가: 상자를 눌러 고르거나, 사진을 끌어다 놓기 (여러 장 가능)
- 사진 목록: 최근에 넣은 사진부터 격자로 보기
- 크게 보기: 사진을 누르면 크게 보여요
- 삭제: 크게 보기 화면에서 삭제
- 저장: 사진은 브라우저(IndexedDB)에 저장되어 새로고침해도 남아 있어요
  (다른 브라우저나 기기와는 공유되지 않아요)

### 실행 방법
```bash
cd app
python3 -m http.server 8000
```
그런 다음 브라우저에서 http://localhost:8000 을 여세요.

### 파일 구성
| 파일 | 역할 |
| --- | --- |
| `app/index.html` | 화면 구조 |
| `app/style.css` | 디자인 |
| `app/app.js` | 동작 (사진 저장·표시·삭제) |
