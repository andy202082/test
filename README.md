## 📷 사진통 (Photo Box)

브라우저에서 동작하는 간단한 사진 보관 앱입니다. 설치할 것이 없어요.

### 기능
- 사진 추가: 상자를 눌러 고르거나, 사진을 끌어다 놓기 (여러 장 가능)
- 폴더째로 불러오기: 「📁 폴더째로 불러오기」 버튼이나 폴더를 끌어다 놓기
  (하위 폴더까지 찾아서 사진만 넣어요)
- 사진 목록: 최근에 넣은 사진부터 격자로 보기
- 크게 보기: 사진을 누르면 크게 보여요
- 삭제: 크게 보기 화면에서 삭제 (한 번 더 확인)
- 저장: 사진은 브라우저(IndexedDB)에 저장되어 새로고침해도 남아 있어요
  (다른 브라우저나 기기와는 공유되지 않아요. 저장이 막힌 브라우저에서는 안내 문구가 나오고, 새로고침 전까지만 보관돼요)
- 어두운 화면 모드 지원
- 회원가입 (claude.ai 링크에서만): claude.ai 계정으로 본인 확인을 하고, 닉네임과 한 줄 소개를 정해 회원 명단에 올라가요.
  비밀번호는 받지 않아요. 「내 정보」에서 수정하거나 탈퇴할 수 있어요. 내 컴퓨터에서 연 파일에서는 보이지 않아요.

### 실행 방법
바로 써 보기: https://claude.ai/artifact/C4jx7Py2ERLXdZ1XYKX8MZ (claude.ai에 올린 버전)

내 컴퓨터에서는 `app/index.html`을 더블클릭하거나, 서버로 열 수도 있어요.
```bash
cd app
python3 -m http.server 8000
```
그런 다음 브라우저에서 http://localhost:8000 을 여세요.
